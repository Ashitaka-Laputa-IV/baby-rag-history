# 检索的四种武器

这一节把“检索”拆开。你只需要理解四件事，九个 rung 的检索部分就都能看懂。

## 武器一：语义检索（dense）

把问题和卡片都变成数字向量，找距离最近的。

- 优点：意思相近就能找到，不怕换词。
- 缺点：对专名、编号、年份不敏感；有时“看起来相关”其实没用。

想象你问“前身创办于哪一年”，它能把“成立于 1836 年”找出来，即使没有“前身”两个字。

## 武器二：关键词检索（BM25）

看卡片里有没有问题里的词。

- 优点：专名、数字、罕见词非常准。
- 缺点：换个说法就找不到。

问“开姆尼茨工业大学”，它一定会找含这几个字的卡片；问“那所德国东部的工业大学”，它可能就找不到。

## 武器三：RRF（把两套排名投票合并）

语义检索给一个排名，关键词检索给一个排名。两个排名怎么合？

不能直接把分数相加，因为两边分数根本不是一个尺度。RRF 只看**名次**：

> 一张卡片在任一套里排第 `r` 名，就给它 `1 / (60 + r)` 分；两套的分加起来。

排在前面的卡片得票多；两套都靠前的卡片最占优势。`60` 是一个平滑常数，让第 1 名和第 2 名的差距不要过于极端。

## 武器四：精排（rerank）

前三种都是“快速粗筛”。精排是**把问题和卡片放在一起再读一遍**，重新打分。

它更准，但更慢、更贵，所以只对前 20 张做，最后留 5 张。

一个比喻：

- 语义/关键词检索 = 图书馆员按索引快速抱来 20 本书；
- RRF = 把两个馆员的推荐合并；
- rerank = 你自己坐下来，把 20 本书的目录认真读一遍，挑 5 本。

## 四种武器怎么组合

| rung | 用了什么 |
|---|---|
| `r0_dense` | 只有语义检索 |
| `r1_hybrid` | 语义 + 关键词 + RRF |
| `r2_rerank` | 语义 + 关键词 + RRF + 精排 |
| `r3_hyde` | 先让模型写一段“假答案”，再用假答案去检索，然后同 r2 |
| `r4_multiquery` | 把问题改写成 3 个版本，各查一遍，再合并 |
| `r5_contextual` | 换一套“带上下文说明”的卡片 |
| `r6_raptor` | 除了原始卡片，还能查“摘要卡片” |
| `r7_crag` | 检索完先检查靠不靠谱，不靠谱就重查或弃答 |
| `r8_agentic` | 把检索变成可重复调用的工具，最多 4 轮 |

## 两个“特殊图书馆”

### Contextual：给卡片加一句“这是关于什么的”

有些卡片被剪出来后，开头就是“他”“该市”“该公司”，脱离原文看不懂。

r5 在索引阶段给每张卡片加一句定位说明，比如：

> 这段讲的是增禄的父亲咸成，以及他在厦门的官职。

检索时用“说明 + 原文”，卡片更容易被找对。

### RAPTOR：给一堆卡片写摘要

r6 把卡片聚类，几段合成一段摘要；摘要再聚类，再摘要，形成两层小树。

查资料时，**原始卡片和摘要卡片一起查**。这样既能拿到细节，也能拿到“全局在讲什么”。

## 一个反直觉的点

精排不是永远更好。它会把“语义上很像但没回答问题”的卡片压下去，但也可能把唯一含答案的卡片排到第 6 位，反而丢掉。

所以排行榜里既有 `evidence R@5`（有没有进上下文），也有 `evidence R@1`（有没有排第一）。

## 如果你只记一件事

> 语义找“意思”，关键词找“词”，RRF 合并排名，精排做最后判断；
> 四种武器不是越多越好，组合方式决定结果。

## 检查一下

**问：** 为什么 RRF 不直接把语义分数和关键词分数相加？

**答：** 两种分数尺度不同，直接加会被其中一种支配。RRF 只看名次，所以两种检索的“第 1 名”权重一样。
