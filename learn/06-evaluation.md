# 怎么证明它有效

这一节回答：排行榜里的数字到底在说什么，哪些能信，哪些不能。

## 先把它想成一场考试

- **题库**：30 道原题 + 25 道手写难题 + 10 道 test + 25 道英文公开题。
- **考生**：9 个 rung + adaptive。
- **阅卷老师**：一个语言模型，判断“回答和标准答案是否一致”。

每个考生做同一套题，用同一个 4,000 token 预算，才能比。

## 两个最基本的问题

### 1. 答对了吗？

`可答 acc` = 可回答问题里，答对的比例。

为什么强调“可答”？因为题库里有 3 道**没有答案**的题（比如问一个不存在的人）。
这些题不该算进“答对率”，而应该单独看“有没有正确拒答”。

### 2. 该看的资料看到了吗？

`evidence R@k` = 标准答案所在的原文，有没有进入前 k 张卡片。

为什么不是 `doc R@5`（文章级召回）？因为 1,000 篇语料上，前 5 张几乎总能命中正确的文章，
这个指标大家都接近 100%，没有区分度。真正有区分度的是**卡片级**：

- `evidence R@1`：正确答案的原文是不是第一张；
- `evidence R@5`：有没有进最终上下文（生成器只看 5 张）。

判断“这张卡片里有没有标准答案原文”，代码其实很朴素：

```python
def evidence_in(text, evidence):
    a, b = norm(text), norm(evidence)
    return b in a or (len(b) >= 12 and b[:12] in a)
```

多跳题还会看 `doc all@5`：**所有**相关文章都要进前 5，而不是“任意一个”。

## 一个曾经的错误：分母不一样

最初的排行榜把 r0–r6 和 r7/r8 放在同一列，但它们的分母不同：

- r0–r6 没有弃答能力，3 道无答案题被跳过 → acc = 24/27。
- r7/r8 有弃答，3 道题计入 → acc = 28/30。

两个百分比不可比。现在的规则是：

- 所有 rung 的 `可答 acc` 都只算 27 / 25 道可答题；
- 所有 rung 都单独报 `弃答 acc`，不会弃答的 rung 得 0。

代码里就是这一分支：

```python
if should_abstain:
    out["correct"] = None          # 不进可答分母
    out["abstain_correct"] = int(abstain)
else:
    out["abstain_correct"] = None
    out["correct"] = judge(...)    # 或 0（弃答/空答案）
```

## 置信区间：30 道题的 90 分不一定是真的 90 分

如果 30 道题答对 27 道，真实水平可能是 80%，也可能是 97%。

所以报告用 **Wilson 95% 区间**：它告诉你“如果换一批同难度的题，成绩大概率落在这个范围”。

样本越小，区间越宽。10 道题的测试集，9/9 全对的区间仍有大约 [70%, 100%]。
**看到 1–2 道题的差距，先看区间是否重叠。**

## 阅卷老师的偏差

用语言模型当阅卷老师，有三个已知问题：

- **位置偏差**：答案放在前面还是后面，分数可能不同。
- **自我偏好**：它可能偏爱和自己风格相似的答案。
- **宽松/严格**：它可能把“差不多”判成对。

项目做了两件事：

1. **A/B 对调**：同一道题，正常顺序判一次，把“回答”和“参考答案”位置对调再判一次；
   30 条抽样里 30/30 一致。

```python
first = llm.invoke(JUDGE.format(...), stage="judge")
second = llm.invoke(JUDGE_SWAP.format(...), stage="judge_swap")
agree = parse_score(first.text) == parse_score(second.text)
```
2. **人工抽检**：目前没有，这是已知缺口。

## 综合分是什么

排行榜有一列“综合”，公式是：

```text
100 × (0.50×可答 acc + 0.30×evidence R@1 + 0.20×MRR) / (1 + 100×冷启动 $/q)
```

人话：

- 50% 看答对；
- 30% 看第一张卡片对不对；
- 20% 看排序质量；
- 再按成本打一点折扣，避免“贵三倍但只好一点”的 rung 占便宜。

代码只有三行：

```python
quality = (0.50 * entry["accuracy"]
           + 0.30 * entry["chunk@1"]
           + 0.20 * entry["mrr@10"])
factor = 1 / (1 + 100 * entry["usd_cold_per_query"])
entry["composite"] = round(100 * quality * factor, 1)
```

## 结果怎么读

- **r5 contextual** 在原题、masked、难题三套里最强：说明“给卡片补语境”真的有用。
- **r2 rerank** 总是前三，成本几乎不变：性价比最高。
- **r3 HyDE** 答对率不低，但 `evidence R@1` 很差：假答案会把正确卡片挤掉。
- **r8 agentic** 没有想象中强：多查几次不等于第一次查得更准。

## 不能信的结论

- 30 题、25 题、10 题都很小；不要拿 1 道题的差异下结论。
- 公开集只有 25 道英文手册，不是中文语料的外部验证。
- faithfulness 只抽了 30 条，29 条满分；它抓不出细微差别。
- masked 只去掉了一部分标题线索，不是完全去偏。

## 如果你只记一件事

> 看 RAG 评测，先看分母是否一致，再看召回是不是卡片级，最后看置信区间；
> 单看一个准确率，很容易被小样本骗。

## 检查一下

**问：** 为什么 r0–r6 的 `可答 acc` 不把 3 道无答案题算进去？

**答：** 因为它们没有弃答路径，算进去会用“不能弃答”惩罚它们，混入能力差异；无答案题单独用 `弃答 acc` 衡量。
